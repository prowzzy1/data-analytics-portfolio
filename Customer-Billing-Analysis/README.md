# 📊 Customer Billing Analysis

## 📌 Overview
This project analyzes customer billing data to identify patterns in account status, billing errors, and issue resolution times. The goal is to uncover insights that can improve billing accuracy and reduce customer dissatisfaction.

---

## 🛠️ Tools Used
- Python
- Pandas
- Seaborn
- Jupyter Notebook

---

## 🔍 Key Insights
- Suspended accounts tend to have higher outstanding balances.
- Billing errors contribute to customer dissatisfaction.
- The most common issues are late payments and overcharges.
- Complex issues require longer resolution times.

---

## 💡 Business Recommendations
- Improve billing accuracy to reduce errors.
- Implement alerts for high balances to prevent account suspension.
- Focus on resolving common issues faster to improve customer experience.

---

## 📁 Dataset
Simulated dataset including:
- Customer ID
- Account status
- Amount due
- Billing errors
- Issue types
- Resolution time
